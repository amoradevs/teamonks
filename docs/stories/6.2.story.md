# Story 6.2: Novo material de Downloads — Cartilha "Redefinindo Perspectivas"

## Contexto
Adiciona um 4º card à seção "Materiais" (Downloads) do hub TEAMONKS, com base na cartilha interna **"Redefinindo Perspectivas — Uma cartilha sobre Neurodiversidade"** (People Experience Brazil, Media.Monks, 2023). O conteúdo do card resume, com identidade visual própria, os conceitos e boas práticas já presentes na cartilha original (deficiência oculta, neurodiversidade, capacitismo, tokenismo, interseccionalidade, e um checklist do que evitar/fazer na avaliação de desempenho de pessoas neurodivergentes).

## O que foi feito
- [x] Criada a página `/downloads/cartilha-neurodiversidade`, seguindo o mesmo padrão das 3 páginas de download existentes (header colorido, botão "Imprimir / Salvar como PDF", conteúdo em seções, footer com fonte).
- [x] Adicionado o 4º item ao array `DOWNLOADS` em `src/app/teamonks/page.tsx`.
- [x] Ajustado o grid de cards de `sm:grid-cols-3` para `sm:grid-cols-2 lg:grid-cols-4`, e adicionada a 4ª cor (laranja) ao array de cores dos cards, mantendo o mesmo padrão visual (barra colorida no topo, ícone com ring, botão "Abrir / Salvar PDF").

## File List

## Critérios de Aceite
- O card "Redefinindo Perspectivas" aparece na seção "Materiais" da home do TEAMONKS, com a mesma identidade visual dos outros 3 (barra de cor, ícone, título, descrição, botão de abrir/salvar).
- A página do material abre em `/downloads/cartilha-neurodiversidade`, com botão de impressão/PDF funcional, mesma estrutura de header/seções/footer das páginas irmãs.
